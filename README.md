# Frank Design Pro

本项目使用 [Ant Design Pro](https://pro.ant.design) 进行初始化。以下是快速使用指南。

## 环境准备

安装 `node_modules`:

```bash
npm install
```

or

```bash
yarn
```

## 提供的脚本

Frank Design Pro 提供了一些实用脚本，可帮助您快速上手并构建 Web 项目，进行代码风格检查和测试。

脚本位于 `package.json` 文件中。您可以安全地修改或添加其他脚本。

### 项目启动

```bash
npm start
```

### 项目构建

```bash
npm run build
```

### 检查代码风格

```bash
npm run lint
```

你还可以使用脚本自动修复一些代码检查错误：

```bash
npm run lint:fix
```

### 测试代码

```bash
npm test
```
